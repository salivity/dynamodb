Required Headers for DynamoDB HTTP API Requests

When making direct HTTP requests to Amazon DynamoDB endpoints without an official AWS SDK, requests must include specific HTTP headers to authenticate, route, and parse the call correctly. This guide identifies the mandatory headers required by the DynamoDB API, focusing on the critical X-Amz-Target parameter and standard AWS Signature Version 4 authentication headers.

The Critical Header: X-Amz-Target

The primary and most distinctive header parameter required by DynamoDB is X-Amz-Target. Because DynamoDB uses a unified endpoint URL for all operations, it relies on this header to determine which API action to execute.

The format for this header is:

X-Amz-Target: DynamoDB_<API_VERSION>.<OPERATION_NAME>

For the current API version (20120810), common examples include:

  • X-Amz-Target: DynamoDB_20120810.GetItem
  • X-Amz-Target: DynamoDB_20120810.PutItem
  • X-Amz-Target: DynamoDB_20120810.Query
  • X-Amz-Target: DynamoDB_20120810.Scan

If this header is missing or malformed, the DynamoDB endpoint returns an UnknownOperationException or a 400 Bad Request error.

Complete List of Required Headers

A direct HTTP request to a DynamoDB endpoint will only succeed if the following complete set of headers is provided:

  1. X-Amz-Target
    • Specifies the exact target operation and DynamoDB API version.
  2. Content-Type
    • Must always be set to application/x-amz-json-1.0. DynamoDB communicates strictly via this JSON specification.
  3. Host
    • The regional DynamoDB endpoint (for example, dynamodb.us-east-1.amazonaws.com).
  4. X-Amz-Date (or Date)
    • The current UTC timestamp formatted in ISO 8601 basic format (e.g., 20231024T120000Z). This value must match the timestamp used when calculating the AWS signature.
  5. Authorization
    • Contains the AWS Signature Version 4 (SigV4) token. It includes your access key ID, the credential scope (date, region, service), signed headers list, and the generated HMAC-SHA256 signature.

Example HTTP Request

Below is an example of a raw POST request sent directly to DynamoDB:

POST / HTTP/1.1
Host: dynamodb.us-east-1.amazonaws.com
X-Amz-Target: DynamoDB_20120810.GetItem
Content-Type: application/x-amz-json-1.0
X-Amz-Date: 20231024T120000Z
Authorization: AWS4-HMAC-SHA256 Credential=AKIAIOSFODNN7EXAMPLE/20231024/us-east-1/dynamodb/aws4_request, SignedHeaders=content-type;host;x-amz-date;x-amz-target, Signature=exampleGeneratedSignatureValue

{
    "TableName": "Users",
    "Key": {
        "UserId": {"S": "12345"}
    }
}

All direct calls to DynamoDB must use the POST method. Providing X-Amz-Target alongside the SigV4 Authorization and Content-Type headers ensures the endpoint correctly validates and processes the request.
