Query and Manage DynamoDB in AWS Console

Managing and querying data in Amazon DynamoDB does not require writing custom scripts or using command-line utilities. Inside the AWS Management Console, the DynamoDB Item Explorer serves as the primary visual tool for interacting directly with your DynamoDB tables. This article explains how the Item Explorer works, its visual query and scan capabilities, and how to leverage it to inspect, create, and update items efficiently without leaving your browser.

The Built-in Tool: DynamoDB Item Explorer

The DynamoDB Item Explorer is the native graphical interface embedded within the Amazon DynamoDB console. It enables developers and database administrators to visually browse tables, construct queries, apply filters, and perform full CRUD (Create, Read, Update, Delete) operations on individual items.

Alongside the visual Query and Scan interface, the console also provides an integrated PartiQL Editor, allowing you to execute SQL-compatible statements directly against your DynamoDB data.

Accessing the Item Explorer

To use the visual management interface:

  1. Sign in to the AWS Management Console.
  2. Navigate to the Amazon DynamoDB service dashboard.
  3. In the left navigation pane, select Explore items.
  4. Choose the target table from the list to display its schema, indexes, and stored items.

Visual Query and Scan Operations

Once a table is selected, the Item Explorer provides two primary operations for retrieving data:

  • Query: Retrieves items based on primary key values. The interface provides input boxes for the Partition Key and an optional Sort Key condition (such as equals, begins with, or between). You can also visually define projection expressions to limit returned attributes and apply filter expressions to narrow down results before they are displayed.
  • Scan: Reads every item in the table or secondary index. The console allows you to configure attribute filters directly through visual dropdowns and input fields, avoiding the need to write manual JSON expression syntax.

Both modes support selecting Global Secondary Indexes (GSIs) or Local Secondary Indexes (LSIs) directly from a dropdown menu.

Item Management and Viewing Modes

The Item Explorer offers multiple ways to view and modify stored items:

  • Table and JSON Views: You can toggle between a tabular view (useful for flat structures) and a raw JSON view (ideal for inspecting nested attributes, maps, and lists).
  • Inline Creation and Editing: Selecting Create item opens an attribute editor where you can add attributes of any supported data type (String, Number, Binary, Boolean, Null, List, or Map). Existing items can be edited or deleted with a single click.
  • Batch Actions: You can select multiple items simultaneously to perform bulk deletions directly from the console.

The Integrated PartiQL Editor

For users who prefer SQL syntax over form-based filtering, the AWS console includes the PartiQL Editor. Accessible from the navigation sidebar, this interface allows you to run standard SELECT, INSERT, UPDATE, and DELETE queries against DynamoDB tables, bridging the gap between relational querying habits and NoSQL data structures.
