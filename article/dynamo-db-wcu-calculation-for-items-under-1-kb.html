DynamoDB WCU Calculation for Items Under 1 KB

Amazon DynamoDB uses Write Capacity Units (WCU) to meter and provision write throughput on tables and global secondary indexes. This article explains how DynamoDB calculates write capacity for items smaller than one kilobyte (KB), detailing the mandatory rounding rule, differences between write operation types, and how individual item sizes are evaluated during batch updates.

The 1 KB Rounding Rule

In DynamoDB, one Write Capacity Unit represents one write per second for an item up to 1 KB in size. DynamoDB always rounds item sizes up to the nearest 1 KB increment when calculating throughput consumption.

If an item's total size is less than 1 KB (for example, 250 bytes or 800 bytes), DynamoDB rounds that size up to 1 KB. Therefore, writing any single item under 1 KB consumes a minimum baseline of 1 KB of write capacity.

Standard Writes vs. Transactional Writes

The actual number of WCUs consumed by an item under 1 KB depends on the type of write operation being performed:

  • Standard Writes: Single-item operations like PutItem, UpdateItem, and DeleteItem consume 1 WCU for an item under 1 KB. Even if an item is completely empty or deleted, the operation consumes 1 WCU.
  • Transactional Writes: The TransactWriteItems operation provides atomicity, consistency, isolation, and durability (ACID) by performing two internal write operations (prepare and commit). Because of this overhead, transactional writes consume twice the normal capacity. Writing an item under 1 KB within a transaction consumes 2 WCUs.

How Item Size Is Determined

An item's size is not based solely on the raw value data. DynamoDB computes the size of an item by adding:

  1. The length of all attribute names in UTF-8 bytes.
  2. The length of all attribute values in UTF-8 bytes (or raw bytes for binary types).
  3. One byte of system overhead for each attribute.

If the sum of these components is anywhere from 1 byte to 1,024 bytes, the item is classified within the initial 1 KB tier, requiring 1 standard WCU (or 2 transactional WCUs).

Evaluation in Batch Operations

When using BatchWriteItem, DynamoDB does not aggregate the total byte count of all items before applying write capacity calculations. Instead, each PutItem or DeleteItem request in the batch is evaluated independently.

For instance, if a single BatchWriteItem request writes ten items that are each 400 bytes, DynamoDB rounds each item up to 1 KB individually. The operation consumes 10 WCUs (1 WCU per item), rather than combining the 4,000 total bytes into 4 WCUs.
