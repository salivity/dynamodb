DynamoDB Limit Parameter: Restrict Returned Items

In Amazon DynamoDB, the Limit parameter is used to restrict the maximum number of items processed and returned by read operations such as Query and Scan. This article explains how the Limit parameter works, highlights crucial behavior differences when using filter expressions, and covers how to handle pagination to retrieve subsequent sets of results efficiently.

The Limit Parameter

When invoking the Query or Scan API operations in Amazon DynamoDB, you can specify the Limit parameter as a positive integer. This parameter tells DynamoDB the maximum number of items to evaluate before returning the response.

For example, setting "Limit": 10 requests that DynamoDB evaluate up to 10 items matching the primary key criteria before returning the result.

Interaction with Filter Expressions

A common point of confusion is how Limit interacts with a FilterExpression:

  • DynamoDB applies the Limit before evaluating any FilterExpression.
  • If you set a Limit of 10 and include a FilterExpression, DynamoDB reads up to 10 items that meet your key condition, applies the filter to those 10 items, and returns only the ones that match.
  • Consequently, the response may contain fewer items than the specified Limit, or even zero items, even if more matching items exist later in the table or partition.

Handling Pagination with LastEvaluatedKey

If the number of evaluated items reaches the value set by Limit, or if the result reaches DynamoDB's hard 1 MB payload size limit, DynamoDB stops processing and includes a LastEvaluatedKey element in the response.

To retrieve the next page of results:

  1. Check the response for the presence of LastEvaluatedKey.
  2. Send a new Query or Scan request.
  3. Pass the returned LastEvaluatedKey into the ExclusiveStartKey parameter of the new request.
  4. Repeat this process until LastEvaluatedKey is empty or no longer returned.

The 1 MB Size Limit

Regardless of the value assigned to Limit, DynamoDB enforces an automatic 1 MB limit on the total data evaluated in a single operation. If DynamoDB hits the 1 MB threshold before reaching your configured Limit, it immediately halts execution, returns the data read so far, and supplies a LastEvaluatedKey to continue reading.
