Describe DynamoDB Table Structure in AWS CLI

This article covers the specific AWS Command Line Interface (CLI) command used to inspect the structure and configuration of an Amazon DynamoDB table. You will learn the exact syntax for the describe-table command, essential parameters, how to filter the output, and what key metadata to look for in the returned JSON response.

The AWS CLI command used to describe the structure, schema, and current status of a DynamoDB table is aws dynamodb describe-table.

Basic Command Syntax

To retrieve the table definition, run the command with the required --table-name parameter:

aws dynamodb describe-table --table-name <YourTableName>

Replace <YourTableName> with the exact name of the table you want to inspect.

Example

To inspect a table named Users:

aws dynamodb describe-table --table-name Users

Key Components of the Output

The command returns a JSON object under the Table key containing full metadata about the table. The most important structural sections include:

  • AttributeDefinitions: Lists the names and data types (e.g., S for String, N for Number, B for Binary) of attributes used as primary keys or index keys.
  • KeySchema: Defines the primary key structure, distinguishing between the partition key (HASH) and the sort key (RANGE).
  • TableStatus: Shows the current operational state of the table (e.g., ACTIVE, UPDATING, DELETING).
  • BillingModeSummary / ProvisionedThroughput: Indicates whether the table is set to On-Demand or Provisioned capacity, along with read and write capacity units if provisioned.
  • GlobalSecondaryIndexes / LocalSecondaryIndexes: Details any secondary indexes, including their key schemas and projection settings.
  • ItemCount and TableSizeBytes: Displays approximate statistics regarding the total number of items and storage consumption.

Filtering the Output

You can use the --query parameter to extract specific structural elements using JMESPath expressions.

View only the primary key schema:

aws dynamodb describe-table --table-name Users --query "Table.KeySchema"

Check only the table status:

aws dynamodb describe-table --table-name Users --query "Table.TableStatus" --output text
